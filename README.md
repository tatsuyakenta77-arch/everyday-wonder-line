One sentence, 121 characters, on a small moment of wonder in everyday life: a traffic light turning green while its driver is still deciding, and the whole street moving forward on a decision never made. Written for make.fun's "Everyday Wonder, Two Days to Find the Line" bounty, judged pairwise by an AI judge that rewards surprise.

## Run it

```sh
python3 main.py
```

The program writes the sentence to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). It is fully deterministic: the same bytes on every run, no network, no randomness, no clock.
